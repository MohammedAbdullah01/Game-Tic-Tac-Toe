# Tic-Tac-Toe (Windows Forms)

## Overview
This is a simple **Tic-Tac-Toe** game built using **C# Windows Forms**. The game supports two players and tracks their scores over multiple rounds.

## Features
- 🎮 **Two-player gameplay** (Player 1 vs. Player 2)
- 🏆 **Round-based system** with score tracking
- 🔄 **Reset game** functionality
- ✅ **Win condition detection**
- ❌ **Prevents invalid moves**

## Technologies Used
- **C#**
- **Windows Forms (WinForms)**
- **Event Handling**
- **OOP Principles**

## How to Play
1. Player 1 (X) starts first.
2. Players take turns clicking on empty squares.
3. The game detects a winner when a player aligns 3 marks (horizontally, vertically, or diagonally).
4. If all squares are filled without a winner, it's a draw.
5. Click "Reset" to start a new round.

## Code Structure
- `Form1.cs` → Main game logic and UI interactions.
- `stInformationPlayer.cs` → Player information struct.
- `stInformationRound.cs` → Round information struct.
- `GameLogic.cs` → Handles win conditions and turn switching.
